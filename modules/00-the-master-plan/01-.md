
## Welcome to the Linux System Admin Course

This course takes you from zero to capable sysadmin through 60 structured parts. Every part builds on the last. Every command is meant to be typed, not just read.

The path ahead is long, but each step is small and practical. You will not just learn Linux — you will learn to think like a sysadmin.

### How This Course Is Different

- Every part follows a consistent structure so you always know where you are
- Each topic is broken into three levels: Basic, Intermediary, and Advanced
- Real commands, real servers, real problems — no toy examples
- Exercises at the end of every section to lock in what you learned

### Your Starting Point

You do not need prior Linux experience. You do need a terminal — a virtual machine, WSL on Windows, or a cloud instance will all work. The only requirement is willingness to type every command yourself.
