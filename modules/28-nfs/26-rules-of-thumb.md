## 📏 Rules of Thumb

### The NFS Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Use NFSv4** | Better performance | Modern |
| **Lock ports** | For firewall rules | Security |
| **Use hard mount** | Prevent data loss | Reliability |
| **Test with showmount** | Verify exports | Debugging |

---

**Why these rules matters:** Following these rules ensures reliable NFS performance and security.
