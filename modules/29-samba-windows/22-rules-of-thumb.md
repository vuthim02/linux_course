## 📏 Rules of Thumb

### The Samba Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Disable SMB1** | It's insecure | Security |
| **Use testparm** | Verify config | Prevent errors |
| **Set permissions** | Match Windows expectations | Compatibility |
| **Document shares** | Know what's shared | Maintainability |

---

**Why these rules matters:** Following these rules ensures secure and reliable Windows integration.
