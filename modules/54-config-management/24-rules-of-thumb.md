## 📏 Rules of Thumb

### The CM Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Version control playbooks** | Git for configs | Auditability |
| **Use idempotent tasks** | Same result every time | Reliability |
| **Test changes first** | Dry run before apply | Safety |
| **Document roles** | Know what each does | Maintainability |

---

**Why these rules matters:** Following these rules ensures consistent and reliable configuration management.
