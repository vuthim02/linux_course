## 📏 Rules of Thumb

### The Security Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Defense in depth** | Layer controls | Redundancy |
| **Least privilege** | Give only what's needed | Security |
| **Default deny** | Block, then allow | Safety |
| **Audit regularly** | Check for drift | Compliance |
| **Monitor logs** | Detect attacks | Detection |

---

**Why these rules matters:** Following these rules ensures effective security posture.
