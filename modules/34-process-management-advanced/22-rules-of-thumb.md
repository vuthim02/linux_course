## 📏 Rules of Thumb

### The Advanced Process Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Check /proc first** | Most info is there | Complete picture |
| **Use strace for debugging** | See system calls | Root cause |
| **Monitor cgroups** | Resource isolation | Performance |
| **Check file descriptors** | Leak detection | Stability |

---

**Why these rules matters:** Following these rules helps you diagnose complex process issues.
