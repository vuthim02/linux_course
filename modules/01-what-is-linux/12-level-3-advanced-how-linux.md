> **Level 3 Goal:** Understand the full path of a command from your fingertips through the shell to the kernel, and learn how /proc provides live kernel data as files.

### What You'll Cover
- The path of a command: shell → fork → exec → kernel
- System calls and the kernel interface
- The `/proc` virtual filesystem
- Reading live kernel data as regular files
