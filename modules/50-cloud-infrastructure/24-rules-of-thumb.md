## 📏 Rules of Thumb

### The Cloud Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Tag everything** | Know what you're paying for | Cost management |
| **Use IAM** | Not root credentials | Security |
| **Enable logging** | CloudTrail/audit logs | Compliance |
| **Use reserved instances** | For predictable workloads | Cost savings |

---

**Why these rules matters:** Following these rules ensures cost-effective and secure cloud operations.
