## 📏 Rules of Thumb

### The Memory Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Monitor memory usage** | Catch pressure early | Proactive |
| **Use swap wisely** | Not too much, not too little | Balance |
| **Check /proc/meminfo** | Know your memory state | Visibility |
| **Tune OOM killer** | Protect critical processes | Reliability |

---

**Why these rules matters:** Following these rules ensures reliable memory management.
