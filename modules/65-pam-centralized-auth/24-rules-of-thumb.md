## 📏 Rules of Thumb

### The PAM Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Test PAM changes** | Use a spare terminal | Don't lock yourself out |
| **Use required/requisite** | For critical checks | Security |
| **Audit PAM configs** | Review regularly | Compliance |
| **Centralize with LDAP** | One source of truth | Manageability |

---

**Why these rules matters:** Following these rules ensures reliable authentication management.
