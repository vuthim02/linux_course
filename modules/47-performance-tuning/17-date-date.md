| Section | What to Include |
|---------|----------------|
| **System Overview** | Hardware, OS, kernel version, uptime |
| **CPU Findings** | Top processes, load average, context switches |
| **Memory Findings** | Swap usage, cache hit ratio, OOM events |
| **Disk I/O Findings** | IOPS, await, queue depth, filesystem usage |
| **Network Findings** | Bandwidth, retransmits, buffer overflows |
| **Recommendations** | Prioritized list of tuning actions |
