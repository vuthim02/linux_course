## 📏 Rules of Thumb

### The Hardening Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Default deny** | Block everything, allow only needed | Security |
| **Least privilege** | Minimum required permissions | Security |
| **Patch regularly** | Fix known vulnerabilities | Compliance |
| **Audit continuously** | Check for drift | Visibility |
| **Document everything** | Know what you hardened | Maintainability |

---

**Why these rules matters:** Following these rules ensures robust system security.
