## 📏 Rules of Thumb

### The Database Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Size buffer pool properly** | 70-80% of RAM | Performance |
| **Test restores** | Verify backups work | Recovery |
| **Monitor connections** | Prevent exhaustion | Stability |
| **Use indexes** | Speed up queries | Performance |

---

**Why these rules matters:** Following these rules ensures database performance and reliability.
