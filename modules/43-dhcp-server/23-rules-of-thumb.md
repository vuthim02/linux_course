## 📏 Rules of Thumb

### The DHCP Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Always test config** | `dhcpd -t` | Prevent failures |
| **Use reservations** | For servers | Stability |
| **Log everything** | Debugging | Evidence |
| **Document pools** | Know what's assigned | Maintainability |

---

**Why these rules matters:** Following these rules ensures reliable DHCP service.
