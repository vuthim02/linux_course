### Why This Part Matters
DHCP automates IP address assignment — without it, manually configuring every device on the network is impossible at scale. Understanding DHCP server configuration ensures reliable network access and prevents conflicts that can take down entire subnets.

> **Real-world perspective**: A misconfigured DHCP server can assign duplicate IPs, hand out wrong DNS servers, or leave devices without connectivity. In large environments, DHCP is the first point of contact for every device joining the network — getting it right is critical.
