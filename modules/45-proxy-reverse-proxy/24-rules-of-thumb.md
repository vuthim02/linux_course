## 📏 Rules of Thumb

### The Proxy Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Use health checks** | Detect failures | Reliability |
| **Log proxy access** | Debug issues | Evidence |
| **Set timeouts** | Prevent hangs | Stability |
| **Use SSL termination** | Offload encryption | Performance |

---

**Why these rules matters:** Following these rules ensures reliable and performant proxy operation.
