## 📏 Rules of Thumb

### The Ansible Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Use check mode first** | Dry run before apply | Safety |
| **Use roles** | Organize code | Reusability |
| **Use vault** | Encrypt secrets | Security |
| **Document everything** | Comments and READMEs | Maintainability |

---

**Why these rules matters:** Following these rules ensures your automation is reliable and secure.
