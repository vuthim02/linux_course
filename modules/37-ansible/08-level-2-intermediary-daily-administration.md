## ⭐ Level 2: Intermediary — Daily Administration

![Ansible modules](https://docs.ansible.com/ansible/latest/_images/ansible_automatic_diagram.png)

> *"Modules are the verbs of Ansible. Master them, and you can describe any server state in YAML."*

### What You'll Cover
- Modules deep dive: `yum`, `apt`, `service`, `user`, `copy`, `template`, `file`, `lineinfile`
- Variables and facts: `host_vars`, `group_vars`, `setup` module, `ansible_facts`
- Jinja2 templates: `template` module, variables, conditionals, loops in templates
- Conditionals and loops: `when`, `loop`, `with_items`, `register`
- Roles: directory structure, `ansible-galaxy init`, role dependencies
- Handlers: notify/on-change patterns, flushing handlers
- Vault: encrypting secrets, `ansible-vault`, vault IDs
- Tags and limits: `--tags`, `--skip-tags`, `--limit`
- Error handling: `ignore_errors`, `block/rescue/always`, `failed_when`, `changed_when`
