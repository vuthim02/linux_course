## 🎯 What You Will Achieve

This module is structured across three progressive levels:

| Level | Focus | What You'll Learn |
|-------|-------|-------------------|
| ⭐ Level 1: Basic — Foundations | Container Concepts & Basics | What are containers, Docker vs Podman, installation, images, Dockerfiles, running containers |
| ⭐ Level 2: Intermediary — Daily Administration | Volumes, Networking, Compose & Security | Volumes and bind mounts, networking, registry, Docker Compose, rootless containers, security, logging |
| ⭐ Level 3: Advanced — Practices & Internals | Practices & Internals | Hands-On Practices, deep understanding (overlay FS, cgroups, namespaces), command reference, self-test |

### Why This Part Matters
Containers changed how applications are deployed. Whether you're running a simple web app or a microservices architecture, understanding Docker and Podman is essential for modern Linux administration. This part builds from `docker run` to production-ready container management with security and networking.

> **Real-world perspective**: Containers are not just a development trend — they are the standard deployment model for modern applications. A sysadmin who cannot build Docker images, troubleshoot container networking, and manage compose stacks is missing the most important infrastructure skill of the past decade.

**Skills progression in this part**:
- **Basic**: Understand containers vs VMs (shared kernel, namespaces, cgroups). Install Docker and Podman. Write Dockerfiles. Run, inspect, and exec into containers.
- **Intermediary**: Manage persistent data with volumes and bind mounts. Configure container networking (bridge, host, custom). Build multi-container apps with Docker Compose. Implement rootless containers and security best practices.
- **Advanced**: Understand overlay filesystem layers. Configure cgroups v2 resource limits. Work with Linux namespaces (PID, NET, MNT, UTS, IPC, USER). Optimize images with multi-stage builds. Know when to reach for Kubernetes.
