## 📏 Rules of Thumb

### The eBPF Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Use BCC tools** | Start with pre-built tools | Efficiency |
| **Check overhead** | Before tracing production | Safety |
| **Read flame graphs** | Focus on wide functions | Performance |
| **Combine with perf** | For comprehensive analysis | Depth |

---

**Why these rules matters:** Following these rules ensures effective system tracing.
