## ⭐ Level 1: Basic Commands

> **Level Goal:** Master the essential Postfix commands for starting, stopping, and inspecting your mail server.

### What You'll Cover
- Starting, stopping, and reloading Postfix
- Inspecting non-default and default configuration parameters
- Viewing the mail queue and basic troubleshooting

| Command | Purpose |
|---------|---------|
| `postfix start` | Start Postfix |
| `postfix stop` | Stop Postfix |
| `postfix reload` | Reload configuration |
| `postconf -n` | Show non-default parameters |
| `postconf -d` | Show all default parameters |
| `postconf <param>` | Show value of a specific parameter |
| `mailq` | List messages in queue |
