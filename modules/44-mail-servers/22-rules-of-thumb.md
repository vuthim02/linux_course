## 📏 Rules of Thumb

### The Mail Server Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Configure SPF/DKIM** | Prevent spoofing | Security |
| **Monitor queue** | Don't let it fill | Reliability |
| **Test delivery** | Verify end-to-end | Correctness |
| **Check logs** | Debug delivery issues | Evidence |

---

**Why these rules matters:** Following these rules ensures reliable and secure email delivery.
