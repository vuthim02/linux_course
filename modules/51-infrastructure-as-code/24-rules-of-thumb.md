## 📏 Rules of Thumb

### The IaC Rules

| Rule | Description | Why |
|------|-------------|-----|
| **Version control everything** | Git for code and infra | Reproducibility |
| **Plan before apply** | Review changes | Safety |
| **Use modules** | Reusable components | Efficiency |
| **Lock state** | Prevent concurrent changes | Integrity |

---

**Why these rules matters:** Following these rules ensures reliable infrastructure management.
