## 🔍 Section 17: tmpfiles, systemd-analyze verify, and Advanced Tools

### systemd-tmpfiles — Manage Temp and Volatile Files

Creates, cleans, and sets permissions on temporary and volatile files at boot.

```bash
# Configuration files
# /usr/lib/tmpfiles.d/     — distro defaults
# /etc/tmpfiles.d/         — admin overrides
# /run/tmpfiles.d/         — runtime config
```

```ini
# /etc/tmpfiles.d/clean-tmp.conf
# Clean /tmp files older than 10 days
d /tmp 1777 root root 10d

# Create a directory with specific perms
d /var/run/myapp 0755 myapp myapp -

# Create a file with content
f /etc/myapp-generated.conf 0644 root root - "generated by tmpfiles"

# Remove on every boot
r /var/cache/myapp-tmp/

# Set permissions on existing path
z /var/log/myapp 0755 myapp myapp -
```

```bash
# Apply manually
sudo systemd-tmpfiles --create   # Create/update files/dirs
sudo systemd-tmpfiles --clean    # Remove old files
sudo systemd-tmpfiles --remove   # Remove marked files
```

### systemd-analyze verify — Validate Unit Files

```bash
# Check a unit file for errors BEFORE deploying
systemd-analyze verify my-service.service

# Check all units in a directory
systemd-analyze verify /etc/systemd/system/*.service

# Common checks:
# - Missing ExecStart
# - Invalid directives
# - Wrong section names
# - Paths that don't exist
```

### systemctl show — Read Unit Properties

```bash
# Show ALL properties of a unit
systemctl show nginx

# Filter specific property
systemctl show -p MemoryMax nginx
systemctl show -p MainPID nginx

# Show property and value only
systemctl show -p MemoryMax --value nginx

# Get multiple properties
systemctl show -p MemoryMax,CPUQuota,TasksMax nginx
```

### systemd-escape — Generate Safe Unit Names

```bash
# Escape paths for use in unit names
systemd-escape "/mnt/data"        # mnt-data
systemd-escape -p "/dev/sda1"     # dev-sda1 (preserve path)
systemd-escape -s -- "--option"   # \x2d\x2doption (shell)
```

### systemd-cat — Pipe Output to Journal

```bash
# Run a command and capture its output in journal
systemd-cat -t mytag echo "Hello from script"
systemd-cat -p emerg "Critical system event"

# In scripts:
exec > >(systemd-cat -t myscript -p info)
exec 2> >(systemd-cat -t myscript -p err)
```

### systemd-run — Run Commands as Transient Units

```bash
# Run a command as a transient service
sudo systemd-run -u my-task -- /usr/bin/long-task.sh

# Run with resource limits
sudo systemd-run -u limited -- \
  -p MemoryMax=100M \
  -p CPUQuota=50% \
  -- /usr/bin/big-job

# Run with a timer
sudo systemd-run --on-calendar="daily" \
  --unit=daily-update /usr/bin/update-check.sh

# Run in user context
systemd-run --user --on-boot=5min /home/user/bin/check.sh
```
